## 在自己電腦上開（不用連結的話）

Finder 打開這個資料夾，雙擊 **啟動武俠班級經營.command**。

終端機視窗會跳出來（不要關掉，關掉遊戲就結束了），瀏覽器自動打開 `http://localhost:8765`。

### Windows 電腦（例如學校電腦）

先確認能不能用 Node：按 `Win+R` 打 `cmd` → 打 `node --version`。

- **有版本號**：雙擊 `啟動武俠班級經營.bat`，跟 Mac 的 `.command` 一樣，黑色視窗不要關
- **沒有，且不能安裝軟體**（學校電腦常見，目前 Steven 的學校電腦就是這樣用）：直接雙擊 `index.html` 開。先測試「新增一位弟子 → 按 F5 → 還在不在」，不在的話代表這台電腦這樣開存不住資料，**每次下課前都要按「📤 備份」下載備份檔**，別只靠自動存檔

**需要連網路**：遊戲的像素圖、角色、音樂是從原作者的 itch.io 伺服器載入的；Excel 匯入功能也需要網路。

### 師尊登入

按右上角「🔑 師尊登入」。**第一次使用會要你自己設定口令**（每台電腦各自設定）。之後登入就輸入這個口令；要改口令到 ⚙️ 設定 →「一般」。

**忘記口令**：在登入框輸入 `admin`，會進入「重設口令」，設定新口令後登入。重設過的話，下一次用正常口令登入會跳出「口令在幾點被重設過」的提醒，如果不是自己重設的，請馬上改口令並檢查資料。

> 這道口令只是把老師的按鈕藏起來，不是資安防護。程式是公開的，懂電腦的學生可能找到重設方法或用開發者工具繞過，重設提醒只能讓你事後發現。

## v4：裝備變生動了

原版角色是一整張畫好的圖，沒辦法真的把武器塞到手上、或讓角色坐上神獸，所以改用武俠裡本來就有的畫面：

| 裝備 | 現在的樣子 |
|------|-----------|
| **神兵** | 化成**飛劍**繞著角色轉，轉到後面會被身體擋住，帶劍光殘影。每把劍光的顏色不同（炎陽劍橘紅、冰晶劍冰藍…）|
| **神獸** | 化成**守護靈**，放大、半透明浮在角色身後，會呼吸發光 |
| **神獸覺醒**（新）| 行囊裡對裝備中的神獸按「覺醒」。2 星 3000 妖丹、3 星 6000 妖丹（v7 起的建議價，設定裡可改），每升一星戰力 +600，守護靈更亮；3 星多一圈旋轉光環。要師尊登入 |
| **氣場**（新）| 萬寶閣「氣場」分頁，600～1200 妖丹。換角色身邊光暈和腳下光圈的顏色，**純外觀不加戰力**，給還買不起神獸的學生一個小目標 |
| **造型**（新）| 原版升到 25／50／75 級會自動換圖。現在解鎖後可以在行囊裡**自己選要穿哪一套**，也可以按「跟著等級自動換」回到原本的行為 |

**隨機歷練也看得到裝備了**：點到名時守護靈跟著現身（訊息會寫「神獸朱雀現身護主！」），答對時飛劍會飛過去砍妖獸。

> 原本想做「衣服換色」，但試過之後濾鏡會連臉一起染色（臉變綠色），原作者的圖片伺服器也不允許程式只挑衣服改，所以改成換氣場顏色。

### 📜 題庫（師尊登入後在上方）
- 一題一題新增：題目、選項 A～D（至少兩個）、圈選正確答案、科目、單元（可不填）
- 或用 Excel 一次匯入，第一列放欄位名稱：

| 題目 | 選項A | 選項B | 選項C | 選項D | 答案 | 科目 | 單元 |
|---|---|---|---|---|---|---|---|
| 「蜿蜒」的意思是？ | 彎曲延伸 | 快速奔跑 | 高聳入雲 | 安靜無聲 | A | 國語 | 第三課 |
| 12 × 8 = ? | 86 | 96 | 106 | | 96 | 數學 | 乘法 |

- 答案可以填 A～D，也可以直接填正確選項的文字
- 匯入前會先預覽，有問題的列會寫出第幾列、什麼問題，可以選「加在後面」或「取代全部」
- 最多 1000 題；題庫會跟著 📤 備份一起帶走

### 🥊 答題對戰
1. 選「個人對戰」或「門派對戰」，左右各選一位（或一派），選題目範圍和每題秒數，按開戰
2. 題目出現在中間，左右兩邊出現**一樣的選項**
   - 電子白板：兩個人各點自己那一邊，可以同時點
   - 鍵盤：左邊按 `1 2 3 4`、右邊按 `7 8 9 0`
3. 每邊只能按一次；按了只顯示「已作答」，**兩邊都答完或時間到才公布**
4. 判定：只有一邊答對就打對方；兩邊都答對，比較快的打；都沒答對沒人受傷
5. 答對後 3 秒自動下一題，也可以按「下一題」；有「暫停」；中途「結束對戰」不發獎勵
6. 門派對戰：每題從那一派**沒請假**的人裡輪流抽一位代表上場，血條整派共用

**戰力差距怎麼算**
- 雙方各 100 血，基本傷害 30（答對 4 題打倒對方）
- 戰力比較高的一方傷害加成 ＝（我方戰力 ÷ 對方戰力 − 1）× 30%，最多 +30%
  - 戰力是對方 1.4 倍以上 → 答對 3 題就能打倒
  - 戰力比較低的一方永遠是 30 → 要答對 4 題，但答得比較好就贏得了
- 門派用「沒請假成員的平均戰力」

**獎勵**（整場只算一步，按一次復原就退回）

| | 贏 | 輸（參加獎） |
|---|---|---|
| 個人 | 妖丹 +50、修為 +30 | 修為 +10 |
| 門派（沒請假的每人） | 妖丹 +30、修為 +20 | 修為 +5 |

**以弱勝強**：贏的一方開場戰力比較低，贏家獎勵 ×2。

## Excel 匯入名單

設定 →「📊 Excel 匯入名單」。吃 `.xlsx` / `.xls` / `.csv`，只讀第一個工作表。

**三種格式都認得**，不用事先整理：
1. 有標題列——認得「座號 / 號碼 / 姓名 / 名字 / 性別 / 門派 / 組別」等欄位名
2. 沒標題，第一欄座號、第二欄姓名
3. 沒標題，只有一列名字（座號用順序遞補）

**性別**：檔案裡有性別欄就用檔案的；沒有就用「第幾號之前（含）是男生」這個分界，預設 15，可以改。

**門派**：檔案裡有門派或組別欄的話，會自動建立同名門派並把弟子指派進去，省掉手動分組。

**匯入前會先預覽**，確認讀到的座號、姓名、性別、門派都對再按「確認匯入」。可以選「追加」（跳過同名）或「取代全部」。匯入後不滿意，按「↩️ 復原」就回去了。

## 一次分派很多人的門派

在「🏯 門派」→「弟子歸屬」。**座號＝名單上的排列順序**（第 1 位就是 1 號）。

| 做法 | 怎麼用 |
|---|---|
| 勾選指派 | 先在「指派到」選門派 → 勾選弟子（整列點一下就能勾）→「指派勾選的人」 |
| 座號區間 | 先在「指派到」選門派 → 填座號（例如 1～8）→「依座號指派」 |
| 平均分配 | 分進**所有現有門派**，人數差最多 1 人。「隨機（男女平均）」每派男女數接近；「照座號輪流」是 1 號進第一派、2 號進第二派這樣輪。勾「只分無門派的」就不會動到已經分好的人 |

每一種都只算一步，分錯按一次「↩️ 復原」就整批退回。平均分配前會先跳出各派人數讓你確認。

## 設定能改什麼

- **師尊口令**（一般）：要先輸入目前的口令才能改
- **萬寶閣價格**（萬寶閣）：神兵、靈獸、氣場、寶箱、覺醒的價格，旁邊顯示「表現好約幾天」；可以還原建議價格。萬寶閣畫面上的「⚙️ 改價格」會直接跳到這頁
- **卡片加扣分按鈕**：原本是 +30／+100／-30／+300 四顆，現在可以改名稱、改數值、新增、刪除，最多 8 顆。項目選「妖丹」就是加扣妖丹（原版只能加修為）。**改完要按「儲存按鈕」**
- **校園特權卡**：名稱、說明、價格都能改，可以新增、刪除（v5）。**改完要按「儲存特權卡」**
- **隨機點名**：開關「抽過的人不會再被抽到」、重設抽籤紀錄
- **存檔**：匯出、匯入、Excel 匯入、重置

每一區都有「還原預設」，改壞了不用怕。

## 資料存在哪裡

存在這台電腦的瀏覽器裡（localStorage），關掉瀏覽器不會消失，但**清瀏覽器資料就會消失**。

每個動作做完都會自動存進瀏覽器，不用手動存檔。

所以：**偶爾按一下工具列的「📤 備份」**（設定裡的「📤 匯出」是同一件事），檔案會下載到「下載」資料夾。備份檔會一併帶走門派與設定（但不含口令），換電腦或重裝時匯入就回來了。

- 按鈕變成「📤 備份 ●」＝有新變動還沒備份
- 有變動沒備份時關網頁（或重新整理），瀏覽器會問「確定要離開嗎？」——按取消留下來，先按備份再關。瀏覽器規定這個提醒的文字不能改，也不能直接在裡面放下載按鈕

新學期要重新開始，用設定裡的「💀 重置」（按錯了還能用復原救）。

## 想改東西的話

整個遊戲就是一個 `index.html`，所有程式碼都在裡面。多數常改的數字現在都能在「⚙️ 設定」裡改，不用碰程式碼。真的要改程式：

| 想改什麼 | 找什麼關鍵字 |
|---------|------------|
| 答對給多少經驗值與妖丹 | `function resolveBattle`，裡面的 `expGain` / `coinGain` |
| 重設口令的字 | `RESET_WORD` |
| 妖獸種類 | `const MONSTERS` |
| 裝備、神獸、稱號的名稱與價格 | `const ITEMS` / `const TITLES` |
| 氣場的顏色與價格 | `const AURAS` |
| 神獸覺醒的價格與加多少戰力 | `AWAKEN_COST` / `AWAKEN_CP_PER_STAR` |
| 造型的名稱與解鎖等級 | `const OUTFITS` |
| 5 把劍集齊後寶箱給多少妖丹 | `ALL_SWORDS_BONUS` |
| 特權卡的名稱與說明 | `const REAL_REWARDS`（價格在設定裡改就好）|
| 門派可選的顏色與徽記 | `SECT_COLORS` / `SECT_EMBLEMS` |
| 復原可以退幾步 | `UNDO_LIMIT` |

新加的功能集中在檔案後段，有註解標示「加購功能」與「v2 加購功能」，好找。

## 檔案說明

| 檔案 | 做什麼 |
|------|--------|
| `index.html` | 整個遊戲（原版 + 新功能）|
| `server.js` | 只給本機用的小伺服器，30 行，不需要安裝套件 |
| `啟動武俠班級經營.command` | Mac 雙擊啟動 |
| `啟動武俠班級經營.bat` | Windows 雙擊啟動（需要有 Node） |

### 為什麼需要 server.js

直接雙擊 HTML 檔（`file://`）開啟的話，瀏覽器對存檔位置的處理不穩定，一學期的資料有被清掉的風險。掛一個小伺服器讓網址固定在 `http://localhost:8765`，存檔位置就穩定。

這個伺服器只綁本機（`127.0.0.1`），同一個網路的其他人連不進來，而且只服務 `index.html` 一個檔案。
