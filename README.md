以 [chunsheng612/GameWuxia](https://chunsheng612.github.io/GameWuxia/) 為基底改的班級經營版本。原版的畫面、音效、答題加分玩法都保留，再加上課堂實際會用到的功能。原作者已同意改作與公開分享。

🔗 **直接開：https://steven770515.github.io/wuxia-class/**

- 不用安裝，重新整理就是最新版（頁面最下面有版本號）
- 資料存在每台電腦自己的瀏覽器裡，不是雲端；換電腦前記得用「📤 備份」
- 需要網路（圖片和音樂從原作者的 itch.io 載入）

## 跟原版比，多了什麼

### 🏯 門派與團隊
- **門派**：立派、改名、徽記顏色，一鍵建立預設六派；可勾選、依座號區間或男女平均一次分好
- **門派榜**：看總和或平均（人數不同也公平）
- **門派任務**：每天自動重置的任務清單（午休安靜、打掃乾淨……），達成的門派有來的人各拿獎勵；「作業全交齊」輸入缺交座號就自動判斷
- **獎賞**：妖丹、修為、聲望一次給一個人、一個門派或全班

### ⚔️ 課堂活動
- **答題對戰**：個人或門派對戰，電子白板兩邊同時點、或用鍵盤。戰力高的傷害略高，戰力低的贏了算「以弱勝強」獎勵加倍。學生下課不用老師登入也能自己打（每人每天前 3 場有獎勵）
- **題庫**：自己出題或用 Excel 匯入，最多 1000 題
- **門派歷練**：隨機歷練可以抽整個門派一起答題
- **世界 Boss**：全班拿到的修為都會打妖王，打倒時有來的人都有獎勵
- **每日奇遇**：老師每天抽一次，當天修為 ×2、萬寶閣八折之類的好消息
- **賽季制**：戰力榜可以只比「這一季」賺到的修為，老師結算發前三名獎勵，新一季大家從 0 開始（裝備、妖丹不會少）

### 🎒 裝備與收集
- **飛劍**：劍會化成飛劍繞著角色轉，**可以掛主劍、副劍兩把**
- **神兵合併**：同一種劍可以有好幾把，**3 把合成 1 把升一級**（最高 +3，每級戰力多 50%）
- **守護靈**：神獸化成守護靈浮在身後，可以花妖丹**覺醒升星**
- **氣場**：換角色光暈顏色，純外觀
- **造型**：升級解鎖後可以自己選要穿哪一套
- **寶箱**：神兵、氣場、靈獸分凡品／靈品／仙品，只開同等級的；靈獸箱不會空箱
- **特權卡寶箱**：隨機開一張特權卡，越便宜的卡越容易開到

### 🌟 武林聲望
- 記「做人」的數值：不能花、不加戰力，累積到門檻就換江湖名號（無名小卒 → 小有名氣 → 名震一方 → 威震武林 → 武林盟主）
- 老師手動給（幫助同學、負責、守規矩），門派任務達成、以弱勝強、打倒世界 Boss 也會加
- 戰力榜有聲望排行

### 🎫 萬寶閣
- 特權卡的名稱、說明、價格都能自己訂（最多 15 張）
- 所有價格老師都能改，旁邊會顯示「表現好的學生約幾天買得到」
- 學生可以自己買東西、開寶箱；買之前會確認「幫誰、花多少」，買錯可以復原

### 🧑‍🏫 老師管理
- **師尊口令**：老師登入後才看得到加扣分、獎賞、設定等按鈕（第一次使用自己設定；忘記時在登入框輸入 `admin` 重設，下次登入會提醒）
- **復原**：加扣分、獎賞、購買、分門派、刪人都能退回上一步（最多 20 步）
- **Excel 匯入名單**：直接讀班級 Excel／CSV，會自動判斷座號、姓名、性別、門派
- **請假**：當天請假的人不會被點名、不會拿全班獎勵，隔天自動恢復
- **抽籤不重複**：抽過的人不會再被抽到，全班抽完自動重來
- **卡片加扣分按鈕**可以自己改名稱和數值，也可以加扣妖丹
- **備份提醒**：有變動沒備份時按鈕會出現 ●，關網頁會跳提醒

### 🔧 修掉的原版問題
- 特權卡按「使用」永遠對不到卡片
- 稱號顯示英文代號（`scholar`）而不是中文名
- 匯入過存檔的弟子按齒輪沒反應
- 有一張戰鬥背景圖失效，畫面變透明
